# Support the project

This is a free community project. Hosting and development have costs, so voluntary donations are welcome.

- A donation is a **gift**: there is no price list, no minimum, and nothing is being sold.
- As thanks, the maintainers may grant supporters **Premium** on the game server (bonus XP / dinar only). Premium never gives weapons or any combat advantage; the goal is a server free of pay-to-win.
- Donations are non-refundable and grant no rights over the server, the code or other players.
- No game client, asset or paid content is distributed.
