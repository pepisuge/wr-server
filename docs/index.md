**wr-server** is an open-source private server for WarRock (2008 FPS), written in plain Node.js.
Login, lobby, rooms, full matches (FFA, TDM, Explosive) with real per-weapon damage, shop, coupons, clans and GM commands work against the real client.

> Not affiliated with, endorsed by or connected to the owners of WarRock or its publishers. No game client, assets or game data are distributed here.

## Documentation

- [Protocol reference](protocol/): how the client and server talk, packet by packet.
- [Contributing](https://github.com/pepisuge/wr-server/blob/main/CONTRIBUTING.md) and the [guide for AI agents](https://github.com/pepisuge/wr-server/blob/main/AGENTS.md).
- [Issue tracker](https://github.com/pepisuge/wr-server/issues): bugs, ideas, roadmap.

## Supporting the project

Donations are voluntary gifts toward hosting and development; nothing is sold. Supporters may receive in-game Premium as a thank-you (XP/dinar bonus only, never a combat advantage). Details in [SUPPORT.md](https://github.com/pepisuge/wr-server/blob/main/SUPPORT.md).
