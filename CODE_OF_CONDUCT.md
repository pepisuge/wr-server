# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, no harassment, discrimination or personal attacks, no doxxing, assume good faith.
Maintainers may remove comments, close issues/PRs and ban accounts that break these rules.
Report problems privately via a GitHub security advisory or by contacting the maintainer @pepisuge.
